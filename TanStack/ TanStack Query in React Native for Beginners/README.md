# TanStack Query in React Native for Beginners

<https://www.youtube.com/watch?v=H0CuK7MPtnI>

```sh
npx create-expo-app@latest query-app 

npm i @tanstack/react-query
npm i -D json-server
```

Add script

```json
"db": "npx json-server --watch data/db.json --port 3000"
```

Add EXPO_PUBLIC_API_URL to .env
