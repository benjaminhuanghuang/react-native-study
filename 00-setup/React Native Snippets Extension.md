
# React Native Snippets Extension

| Shortcut | Expands To                                            | Description                  |
| -------- | ----------------------------------------------------- | ---------------------------- |
| `tsrafc`    | TypeScript React Arrow Function Component                  | Basic RN component           |
| `tsrafce`   | TypeScript React Arrow Function Component + Export                 | Includes style template      |
| `tsrnf`    | → React Native functional component                   | Basic RN component           |
| `tsrnfs`   | → React Native functional component with `StyleSheet` | Includes style template      |
| `rnfc`   | → React Native functional component (arrow function)  | Modern arrow function syntax |
| `imr`    | → `import React from 'react'`                         | Import React                 |
| `imrn`   | → `import { View, Text } from 'react-native'`         | Basic React Native imports   |
| `rnc`    | → React component (web or native)                     | Quick skeleton               |
| `clg`    | → `console.log()`                                     | Logging                      |
| `usf`    | → `useState` snippet                                  | Hook snippet                 |
| `uef`    | → `useEffect` snippet                                 | Hook snippet                 |
